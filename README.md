# 日课 · 每日打卡

每天勾掉要做的事，记下遇到的问题，按周、按月看完成情况，并把记录导出成文字交给 AI 分析。

- **今日**：按「固定事项」自动生成当天清单。点右侧方框划掉一项；可选填实际用时（超过计划 20% 会标红）；可以临时添加或移除某一项（只影响这一天）。下方 Note 有常用原因标签和文字记录。
- **本周**：事项 × 七天的打卡格、这周所有 note，可以复制或下载这一周的记录。
- **本月**：月历、各项完成率、这个月所有 note，可以复制或下载整月记录。
- **周报**：自动统计，并按规则给出调整建议（不调用 AI）。
- **固定事项**：编辑每周固定安排、同步设置和备份。

纯静态网页（index.html、style.css、app.js），GitHub Pages 直接托管；同步通过你自己的 Google 表格完成。

---

## 一、部署到 GitHub Pages

1. 在 GitHub 新建仓库，比如叫 `rike`。免费账户的 Pages 需要仓库是 **Public**。代码公开没关系：打卡记录不在仓库里，口令也不写在代码里。
2. 把 `index.html`、`style.css`、`app.js` 传到仓库根目录。`apps-script/` 和 `README.md` 也可以一起传上去，留作备份。
3. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`，文件夹选 `/ (root)` → **Save**。
4. 一两分钟后访问 `https://你的用户名.github.io/rike/`。

做到这一步就能用了，记录保存在当前浏览器里。

## 二、用 Google 表格同步（可选）

### 1. 建表格、贴脚本

1. 新建一个 Google 表格，命名为「日课记录」。
2. 菜单 **扩展程序 → Apps Script**，打开脚本编辑器。
3. 删掉编辑器里默认的 `function myFunction() {}`，把 `apps-script/Code.gs` 的全部内容粘贴进去，按 ⌘S 保存。

### 2. 设口令

1. 左侧点齿轮 **项目设置**，拉到最下面 **脚本属性 → 添加脚本属性**。
2. 属性填 `APP_TOKEN`，值填你自己定的一串口令（比如 20 位以上的随机字母数字）。
3. 点 **保存脚本属性**。

### 3. 运行一次 setup（授权）

1. 回到编辑器（左侧 `< >` 图标），顶部函数下拉框选 `setup`，点 **运行**。
2. 弹出授权：选你的 Google 账号 → 如果提示“Google 未验证此应用”，点 **高级 → 转至“…”（不安全）→ 允许**。这是你自己写的脚本，只访问这张表格。
3. 运行完后，表格里会多出两张工作表：「打卡记录」和「设置」。

### 4. 部署成网页应用

1. 右上角 **部署 → 新建部署**。
2. 左侧“选择类型”的齿轮里选 **Web 应用**。
3. **执行身份**：我。**有权访问的用户**：任何人。（必须选“任何人”，app 才能访问；有口令保护，别人拿到网址也读写不了。）
4. 点 **部署**，复制 **Web 应用网址**。网址以 `/exec` 结尾，不要用以 `/dev` 结尾的测试网址。

### 5. 在 app 里填写

打开 app →「固定事项」页底部 **同步** → 填入网址和口令 → **保存并同步**。手机、电脑各填一次即可。

之后每次改动约 1.5 秒后自动同步，切回这个网页时也会同步一次。侧栏底部会显示同步状态。

### 修改脚本后

改了 Code.gs 后，要在 **部署 → 管理部署** 里点铅笔 → 版本选 **新版本** → **部署**。这样网址保持不变，app 不用重新填。

### 表格里能看到什么

「打卡记录」每天一行，最近的在最上面：日期、星期、完成数、完成率、计划分钟、实际分钟、未完成的事项、标签、Note。可以直接在表格里查看、筛选，或下载 CSV。
最后两列「数据（勿改）」「更新时间（勿改）」是 app 用的原始数据，**请不要手动修改**；改了前面的列也不会同步回 app，以 app 为准。

## 导出给 AI 分析

在「本周」「本月」或「周报」页点 **复制这周记录 / 复制本月记录**，或 **下载 .md**。导出的文字包括：
- 总体完成率
- 每项的完成次数、计划与实际用时、超时次数
- 原因标签统计
- 每一天完成和未完成的事项、实际用时、标签和 Note
- 没打卡的日子

直接贴给 AI 就能分析。

## 备注

- 同步需要能访问 Google。不挂代理时同步会失败，但不影响使用：记录照常存在本地，下次连上 Google 时自动补同步。
- `github.io` 在国内一般能打开，但偶尔不稳定。
- 没开同步时，记得偶尔在「固定事项」页 **导出备份**，因为清除浏览器数据会删掉本地记录。开了同步的话，表格本身就是备份。
- 两台设备改了同一天时，以最后改动的那台为准。
